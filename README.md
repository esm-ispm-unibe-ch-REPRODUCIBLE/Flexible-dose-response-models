Instructions
How to reproduce the results presented in the article "Flexible dose-response models".
To reproduce the numerical results and the graphs, go through the following steps.

•	You need to have R and R-Studio installed.
•	Double click on "Flexible dose-response.Rproj" file
•	From within R-Studio, open the file in R folder: "00_master.R" and run it, or run directly the "Flexible dose-response models.Rmd".

You need to have the data from catalyst or the synthesized data so that the codes can be run
